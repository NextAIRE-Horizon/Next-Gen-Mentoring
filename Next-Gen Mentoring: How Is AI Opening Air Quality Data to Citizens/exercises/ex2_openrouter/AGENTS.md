# Exercise 2

This folder is the OpenRouter exercise. Help the user create an account and put a key in the host they opened in exercise 1. Cursor, Antigravity, and Visual Studio Code use the OpenAI-compatible base URL. Claude Code uses Francesco Bardozzo’s three Anthropic-shaped variables (`ANTHROPIC_BASE_URL` `https://openrouter.ai/api`, `ANTHROPIC_AUTH_TOKEN`, empty `ANTHROPIC_API_KEY`), via `.claude/settings.local.json` copied from `settings.local.json.example`, or via `install-openrouter-models.sh`. Keep keys off disk in this pack. The same key is used again in exercise 4.

Do not invent Open-Meteo, CAMS, news, or indoor readings.
Do not name commercial indoor monitors, a vendor product line, or a private consultant. This pack has no private sensor API.
Do not put API keys in files in this folder.
