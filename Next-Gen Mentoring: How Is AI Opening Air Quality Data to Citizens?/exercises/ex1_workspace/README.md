# Exercise 1 - Open a host

| Piece | In this exercise |
|-------|------------------|
| **Host** | The IDE you open: Cursor, Visual Studio Code, Claude Code, Codex, Antigravity, or Grok. That application is the runtime. |
| **Harness** | Whatever that product already ships: its chat, its rules, and an MCP client if it has one. You have not added Next-Air-Assistant yet. |
| **Model** | The product default, or none until exercise 2. |

You are inside a host you did not write. Commercial apps sell the host and the harness together.

The zip you unpacked is the project. Open the folder that contains this `ex1_workspace` directory (the pack root) in **one** host. Do not create a second empty folder.

If you still need to install a host, use the links below.

- Cursor: <https://cursor.com/download>
- Visual Studio Code: <https://code.visualstudio.com>
- Claude Code: <https://code.claude.com/docs/en/quickstart>
- Codex: <https://developers.openai.com/codex>
- Antigravity: <https://antigravity.google/download/>

At that pack root you already have `AGENTS.md`, `CLAUDE.md`, and `.gitignore`. That is enough to start. Continue with exercise 2 (choose a model), then exercise 3 (load the plugin in this same host).
